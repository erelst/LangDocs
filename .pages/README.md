# LangDocs

Dokumentasi proyek ini sekarang ada di README.md di akar repo.

Berkas ini dulu menjelaskan build Python (generator template, pemeriksa, dan skrip
verifikasi). Semua berkas Python sudah dihapus: isinya sekarang ditulis, bukan
dihasilkan, dan halaman web-nya membaca berkas data langsung tanpa build step.

Isi deck saat ini **narasi**, bukan kalimat lepas: 13 topik, 156 narasi, masing-masing berjudul.
Berkas pemeriksa JavaScript (`check.js`, `test.js`, `ui.js`, `coverage.js`, `syncdocs.js`) juga
sudah dihapus; yang tersisa di CI hanya pemeriksa sintaks.

Isi terkini: README.md, docs/SPEC.md, docs/JUDUL.md
